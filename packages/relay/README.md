# 接力调度器（`packages/relay`）

让几个 AI 命令行在你自己一直开着的电脑上，一棒接一棒地干活。

## 这是什么

两个角色接力：**整合方（统筹）**负责审、并把该并的并进 `main`、定方向；**开发**负责照规格写、把分支推上去。
**一棒** = 调度器从队列里挑一行、把这一棒的交代写成一个文件、起那个角色的命令行、等它跑完、再核对它有没有越界。
两个角色不直接说话，靠**队列**交接：队列是 `docs/委派/队列.md`，调度器只认 **`origin/main` 上那份**（不读工作区里没推上去的改动）。

## 第一次用

1. **准备一份配置**。调度器要一个「数据目录」，默认在 `%LOCALAPPDATA%\IXAEON\relay`（别的系统是 `~/.local/share/ixaeon/relay`）。目录里要有一份 `config.json`，写着两个角色怎么起、在哪个目录起。
   - **一条命令生成它**：`relay init`（**正在做**，见 L5）。它会：找这台机器上的 Claude Code 可执行文件、在 `<工作目录根>/relay-int` 建一个整合方的专用工作目录（`git worktree`）、把开发的命令行指向仓库里的 DSH 启动器，然后在写出来之前用配置检查过一遍。
   - L5 并入 `main` 之前，这个命令还不存在，得照 `packages/relay/config.example.json` 手写一份。
2. **想收飞书通知就配机器人**。在飞书群里加一个**自定义机器人**、打开**签名校验**，把地址和密钥写进 `<数据目录>/feishu.json`：

   ```json
   {
     "webhookUrl": "https://open.feishu.cn/open-apis/bot/v2/hook/<你自己的那串>",
     "secret": "<你自己的签名密钥>"
   }
   ```

   这个文件不进仓库、也别外传。**不配也能跑**，只是停下和日报没人通知你。
   - 数据目录以前在 `<工作目录根>/relay`，**旧位置的文件不会自动搬**：跑一次 `relay status`，它会提醒你「旧的数据目录里还有文件」。

3. **确认开发那份工作目录**。开发的 `cwd` 是 `<工作目录根>`（就是 `Worktrees/IXAEON` 这一层），因为开发要照 `AGENTS.md` 在它底下用 `git worktree` 建自己的活儿目录；整合方的 `cwd` 是它自己的 `relay-int`，**不和开发共用**。

## 日常怎么使

| 命令                         | 做什么                                                                                      | 什么时候用                 |
| ---------------------------- | ------------------------------------------------------------------------------------------- | -------------------------- |
| `relay once`                 | 看队列定下一棒，跑完一棒就退                                                                | 想盯着看的时候             |
| `relay run`                  | 一直转：有活就跑，没活等 `idleSeconds`（默认 60 秒）再看；**停下**（越界/拉不下来）就自己退 | 让它自己干活               |
| `relay run --exit-when-idle` | 第一次「没活」就退                                                                          | 想让它把当前能干的干完就停 |
| `relay status`               | 打印数据目录、`state.json` 里的状态、最近 5 条记账；旧数据目录还有文件也会提醒              | 看它现在什么状态           |
| `relay resume`               | 清掉 `stoppedReason`                                                                        | 停下之后想接着跑           |

- **怎么停**：`Ctrl+C`；或者 `run` 跑到停点自己退。
- **同一时间只许一个调度器**：数据目录里的 `lock.json` 记着正在跑的进程号，重复启动会被拒（「已经有调度器在转…」）。那个进程不在了，就能再启动。
- **换位置**：环境变量 `IXAEON_RELAY_DIR` 有值时，数据目录用它。
- 启动器认安装目录：`IXAEON_DSH_INSTALL` 有值就只认它，否则依次试 `D:/Agent/DeepSeek Harness/Install`、`%LOCALAPPDATA%/Programs/DeepSeek Harness`。

## 它什么时候会停下来找你

调度器**不会自己改仓库、也不会自己动队列那一行**；它只在下面几种时候停，并把原因写进 `state.json`：

- **越界**：那一棒改了不该改的（比如 B 档任务推了实现、动了锁定验收测试的指纹）。停下，原因长得像
  `第 3 棒越界（developer）：b-tier-lock-changed-by-developer`。
- **核对时拉不下来**：`第 3 棒之后拉不下来 origin/main，没法核对`。
- **要你拍板**：模型照交代把那一行改成「等用户：…」然后停——**这一类要你看一眼**。
- **撞额度**：那个角色歇一段时间（配置里的 `quotaPauseMinutes`），到点自己接着跑。
- **没活**：队列空了、或者剩下的都被依赖挡着。

配了飞书的话，你收到的是这些（第一行固定是「【IXAEON 接力】」）：

- 停下来了：`停下来了：<原因>。`（有任务号还会附一行 `第 N 行：<任务>`）
- 要你拍板：`要你拍板：第 N 行「<任务>」现在是「<状态>」。`
- 撞额度：`统筹撞上额度，歇到 <北京时间>。` / `开发撞上额度，歇到 <北京时间>。`
- 没活（只在 `run` 里发，30 分钟最多一条）：`队列空了，等你排新活。` / `剩下的都被依赖或暂停挡着，等你看一眼。`
- 日报（北京时间 21:00 之后发一次）：`<X月X日> 日报：跑了 N 棒，完成 <任务、任务>。`，有 Claude 用量时再加一行 `Claude 用量折合约 X 美元`。

## 数据目录里有什么

| 文件              | 是什么                                                                                                                                 | 能不能动                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `config.json`     | 两个角色的命令行与 `cwd`、`idleSeconds`、`localUserCheck`                                                                              | 手改要看懂再改（改坏了配置检查会拒绝启动）      |
| `state.json`      | `turns`（跑了几棒）、`stoppedReason`、`pausedUntil`、`notify.sent`（飞书限频）、`lastDailyDate`                                        | **别手改**；`relay resume` 会动 `stoppedReason` |
| `ledger.jsonl`    | 一棒一行：`role`、`kind`、`taskId`、起止时间、退出码、`usage`（Claude 那一棒花了多少）、`statusBefore/After`、`doneLine`、`violations` | 看完想留档就先拷走，删了不影响运行              |
| `turns/<第几棒>/` | `prompt.md`（这一棒的交代）、`stdout.txt`、`stderr.txt`（角色的原样输出）                                                              | 旧目录可以删（排查问题时就靠它）                |
| `lock.json`       | 正在跑的那个进程                                                                                                                       | **别手删**，正常退出会自己清                    |

## 已知的限制

- **给模型的白名单不是围栏**。整合方那串 `PowerShell(git:*) node:* corepack:* gh:*` 挡的是手滑，不是恶意：`node:*`、`corepack:*` 这类等于允许执行任意代码。
- **DSH 的沙箱关不住写文件**。数据目录挪到 `%LOCALAPPDATA%\IXAEON\relay`、配置检查不许角色的 `cwd` 包着数据目录——这两条防的是手滑，不是围栏（真机检查里实测它写进去了）。
- **DSH 自己不推送**。它拿不到本机的 git 凭据（调凭据助手要经过 `sh.exe`，在它的受限令牌下起不来）。**正在做**（L6）：DSH 只提交、在输出里写要推什么，由调度器用你的登录态替它推，且只许 `dev/` 开头的分支和不强推的 `main`。
- **本机 PATH 里没有 `codex`**（真机检查实测）：A 档要的 Codex 审查现在跑不了，要装 `codex` 或把它的路径加进 PATH。
- 队列和核对都只认 **`origin/main`**：开发在自己工作目录里推的分支，得照 `AGENTS.md` 的流程并进 `main` 才算交接完成。
- 这一版只在**一台机器**上跑：`main`、`Worktrees/IXAEON`、数据目录都是本机的。
