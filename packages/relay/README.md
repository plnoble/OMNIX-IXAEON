# 接力调度器（`packages/relay`）

让几个 AI 命令行在你自己一直开着的电脑上，一棒接一棒地干活。

## 这是什么

两个角色接力：**整合方（统筹）**负责审、并把该并的并进 `main`、定方向；**开发**负责照规格写、把分支推上去。
**一棒** = 调度器从队列里挑一行、把这一棒的交代写成一个文件、起那个角色的命令行、等它跑完、再核对它有没有越界。
两个角色不直接说话，靠**队列**交接：队列是 `docs/委派/队列.md`，调度器只认 **`origin/main` 上那份**（不读工作区里没推上去的改动）。

## 第一次用

1. **准备一份配置**。调度器要一个「数据目录」，默认在 `~/.ixaeon/relay`（Windows 上是 `%USERPROFILE%\.ixaeon\relay`；不在 AppData 下面，桌面版不会把它转存走）。目录里要有一份 `config.json`，写着两个角色怎么起、在哪个目录起。
   - **一条命令生成它**：`relay init`（L5，已经有了）。它会：找这台机器上的 Claude Code 可执行文件、在 `<工作目录根>/relay-int` 建一个整合方的专用工作目录（`git worktree`）、把开发的命令行指向仓库里的 DSH 启动器，写出来之后用配置检查过一遍，不过就删掉、说清是哪一条。
   - L5 并入 `main` 之前，这个命令还不存在，得照 `packages/relay/config.example.json` 手写一份。
2. **想收飞书通知就配机器人**。在飞书群里加一个**自定义机器人**、打开**签名校验**，把地址和密钥写进 `<数据目录>/feishu.json`：

   ```json
   {
     "webhookUrl": "https://open.feishu.cn/open-apis/bot/v2/hook/<你自己的那串>",
     "secret": "<你自己的签名密钥>"
   }
   ```

   这个文件不进仓库、也别外传。**不配也能跑**，只是停下和日报没人通知你。
   - 数据目录以前在 `<工作目录根>/relay`，**旧位置的文件不会自动搬**：跑一次 `relay status`，它会提醒你「旧的数据目录里还有文件」。

3. **（可选）定接力的 DSH 用哪个 plan、什么权限**。DSH 的 `headless` 配置自己不带模型设置，默认走 DeepSeek 官方 API，而且关在沙箱里（装不了依赖、跑不了测试）。2026-10-23 起的做法：在 `~/.dsh/ixaeon-relay.patch.yml` 写一层 DSH 补丁（选哪个 provider / model、要不要完全权限），在 `config.json` 开发的命令里 `--profile headless` 后面加 `--patch <这个文件>`。**换 plan 只改这个文件**，下一棒就生效；你平时用的 DSH 桌面版不读它。`relay init` 不会替你加这一项，重新生成配置后要补上。
4. **确认开发那份工作目录**。开发的 `cwd` 是 `<工作目录根>`（就是 `Worktrees/IXAEON` 这一层），因为开发要照 `AGENTS.md` 在它底下用 `git worktree` 建自己的活儿目录；整合方的 `cwd` 是它自己的 `relay-int`，**不和开发共用**。

## 日常怎么使

| 命令                         | 做什么                                                                                                                                                                                                     | 什么时候用                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `relay once`                 | 看队列定下一棒，跑完一棒就退                                                                                                                                                                               | 想盯着看的时候             |
| `relay run`                  | **看门人**：每一轮先把 `<工作目录根>/relay-run` 换到最新 `origin/main`、装好依赖，再起 `once` 跑一棒；有活就跑，没活等 `idleSeconds`（默认 60 秒）再看；**停下**（越界/拉不下来）就自己退；连着崩 3 次也停 | 让它自己干活               |
| `relay run --exit-when-idle` | 第一次「没活」就退                                                                                                                                                                                         | 想让它把当前能干的干完就停 |
| `relay status`               | 打印数据目录、`state.json` 里的状态、最近 5 条记账；旧数据目录还有文件也会提醒                                                                                                                             | 看它现在什么状态           |
| `relay resume`               | 清掉 `stoppedReason`                                                                                                                                                                                       | 停下之后想接着跑           |

- **怎么停**：`Ctrl+C`；或者 `run` 跑到停点自己退。
- **不用重启就吃到新代码**：`relay run` 每一轮都从 `origin/main` 换 `<工作目录根>/relay-run`，并进 `main` 的改进下一棒就生效。看门人自己的那轮**不建 Windows 计划任务、不改系统设置**。
- **开机自己起来**（可选，**你自己建**，调度器不替你建）：Windows 上可以用计划任务，登录后起一次、用普通终端就是我平时那样跑：

  ```bat
  schtasks /create /tn "IXAEON relay" /tr "cmd /c cd /d <本仓库路径> && node packages\relay\bin\relay.mjs run" /sc onlogon /rl limited
  ```

  要先 `cd` 到仓库里：调度器按当前目录找共用检出目录，计划任务默认的当前目录不在仓库里，会起不来（整合方复审时改的）。

  不想要了：`schtasks /delete /tn "IXAEON relay" /f`。

- **同一时间只许一个调度器**：数据目录里的 `lock.json` 记着正在跑的进程号，重复启动会被拒（「已经有调度器在转…」）。那个进程不在了，就能再启动。
- **换位置**：环境变量 `IXAEON_RELAY_DIR` 有值时，数据目录用它。
- 启动器认安装目录：环境变量 `IXAEON_DSH_INSTALL` 有值就只认它；没有就依次试 DSH 桌面版的默认安装位置（`%LOCALAPPDATA%\Programs\DeepSeek Harness`，以及 DSH 安装器常用的那个目录——具体以 `packages/relay/bin/dsh.mjs` 里写的那两个候选为准）。

## 它什么时候会停下来找你

调度器**不会自己改仓库、也不会自己动队列那一行**；它只在下面几种时候停，并把原因写进 `state.json`：

- **越界**：那一棒改了不该改的（比如 B 档任务推了实现、动了锁定验收测试的指纹）。停下，原因长得像
  `第 3 棒越界（developer）：b-tier-lock-changed-by-developer`。
- **核对时拉不下来**：`第 3 棒之后拉不下来 origin/main，没法核对`。
- **要你拍板**：模型照交代把那一行改成「等用户：…」然后停——**这一类要你看一眼**。
- **撞额度**：那个角色歇一段时间（配置里的 `quotaPauseMinutes`），到点自己接着跑。
- **没活**：队列空了、或者剩下的都被依赖挡着（`run` 里每种原因一个北京日只发一次）。

配了飞书的话，你收到的是这些（第一行固定是「【IXAEON 接力】」）：

- 停下来了：`停下来了：<原因>。`（有任务号还会附一行 `第 N 行：<任务>`）
- 要你拍板：`要你拍板：第 N 行「<任务>」现在是「<状态>」。`
- 撞额度：`统筹撞上额度，歇到 <北京时间>。` / `开发撞上额度，歇到 <北京时间>。`
- 做完一件（那一行变成「已完成」时，不限频）：`第 N 行做完了：<任务>`、`一共 N 棒、N.N 小时`，整合方花了钱时再接 `，整合方花了 X.XX 美元`。
- 没活（只在 `run` 里发，每种原因一个北京日最多一条）：`队列空了，等你排新活。` / `剩下的都被依赖或暂停挡着，等你看一眼。`
  `all-blocked` 会再列出状态以「等用户」开头的行（`要你回答的：` 之后一行一条
  `- 第 N 行 <任务>：<状态去掉「等用户」前缀>`）；一行都没有就写「没有要你回答的，你不用做什么。」。
- 早报（配置里 `morningReport` 是 `true` 时，北京时间 9:00 之后发一次）：`早报 <X月X日>：昨晚 9 点到现在跑了 N 棒`，
  有 Claude 用量时接 `，整合方花了 X.XX 美元`；第二行 `做完了：<任务、任务>`（没有就写「这段时间没做完新的」）；
  有任务在做时第三行 `在做：<任务、任务>`。
- 日报（北京时间 21:00 之后发一次）：`<X月X日> 日报：跑了 N 棒，完成 <任务、任务>。`，有 Claude 用量时再加一行 `Claude 用量折合约 X 美元`。
- 规划棒排了新活：`整合方排了 N 件新活：`，之后每行一条 `- 第 <序号> 行 <任务>（<状态>）`。

## 没活时自己排下一批（L9）

队列里没有能接的活（`queue-empty` / `all-blocked`）时，调度器会派一棒**规划棒**给整合方：照 `docs/委派/整合方手册.md` 第 11 节，从 `docs/三周任务单.md` 里挑下一批（最多 3 件），每件写一页规格、在队列主表末尾加一行，推上 `main` 就停。拿不准方向的只加一行「等用户：…」。

- **有限度**：每个北京日最多 `planPerDay` 棒（`relay init` 和 `config.example.json` 里是 `2`；不配、或者 `0`，就完全不规划，和原来一样）。
- **不自己转圈**：队列和上一次派规划棒时一字不差（上次没加出东西、之后也没人改过）就不再规划，照原来空转。
- **只许看、只许写文档**：规划棒只许改 `docs/` 下面的文件，不许动主表里已有的行；越界照样停下。
- 排了新活会发上面那条飞书；一行都没加就不发。

## 数据目录里有什么

| 文件              | 是什么                                                                                                                                 | 能不能动                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `config.json`     | 两个角色的命令行与 `cwd`、`idleSeconds`、`localUserCheck`                                                                              | 手改要看懂再改（改坏了配置检查会拒绝启动）      |
| `state.json`      | `turns`（跑了几棒）、`stoppedReason`、`pausedUntil`、`notify.sent`（飞书限频）、`lastDailyDate`、`idleDay`（没活发到哪天）、`lastMorningDate`                                        | **别手改**；`relay resume` 会动 `stoppedReason` |
| `ledger.jsonl`    | 一棒一行：`role`、`kind`、`taskId`、起止时间、退出码、`usage`（Claude 那一棒花了多少）、`statusBefore/After`、`doneLine`、`violations` | 看完想留档就先拷走，删了不影响运行              |
| `turns/<第几棒>/` | `prompt.md`（这一棒的交代）、`stdout.txt`、`stderr.txt`（角色的原样输出）                                                              | 旧目录可以删（排查问题时就靠它）                |
| `lock.json`       | 正在跑的那个进程                                                                                                                       | **别手删**，正常退出会自己清                    |

## 已知的限制

- **给模型的白名单不是围栏**。整合方那串 `PowerShell(git:*) node:* corepack:* gh:*` 挡的是手滑，不是恶意：`node:*`、`corepack:*` 这类等于允许执行任意代码。
- **DSH 的沙箱关不住写文件**。数据目录是 `~/.ixaeon/relay`（不在 AppData 下面）、配置检查不许角色的 `cwd` 包着数据目录——这两条防的是手滑，不是围栏（真机检查里实测它写进去了）。
- **DSH 自己不推送**。它拿不到本机的 git 凭据（调凭据助手要经过 `sh.exe`，在它的受限令牌下起不来）。所以（L6，已经有了）：DSH 只提交、在输出里写要推什么（`RELAY-PUSH` 行），由调度器用你的登录态替它推，只许 `dev/` 开头的分支和不强推的 `main`；推上去的东西照样核对越界。还差一件：DSH 在共用仓库的工作目录里连提交都提交不了（`.git` 不在它的工作目录里），所以给了它一套自己的仓库（L6b，已经有了）：开发的工作目录根是 `<工作目录根>/dsh`，里面一份自己的克隆 `repo`，它的任务工作目录也建在这底下；`relay init` 会建好。
- **DSH 那一侧没有 `codex` 命令**（真机检查实测：PATH 里找不到，`where.exe` 也找不到）。A 档要的 Codex 审查是**在沙箱外**跑的（`scripts/codex-review.mjs` 会自己找 Codex 桌面版自带的 `codex.exe`，不依赖 PATH）；DSH 那一棒里调不了它。
- 队列和核对都只认 **`origin/main`**：开发把自己那一支推上去、把队列里那一行改成「测试待审／待复审」，**并进 `main` 是整合方的活**（A 档才是自己审过再自己并）。调度器看不到还没进 `main` 的东西。
- 这一版只在**一台机器**上跑：`main`、`Worktrees/IXAEON`、数据目录都是本机的。
