# 项目笔记：星尘计划（测试资料）

这是 IXAEON 的脱敏测试文档，用于验证导入、提取与引用。

## 项目目的

星尘计划的目标是构建一个本地的知识整理工具，帮助个人管理零散笔记。

## 已做决定

1. 界面语言使用简体中文。
2. 数据存储在本机，不使用云服务。

## 已否决方案

- 使用 Notion 作为后端：已否决，因为数据必须留在本机。
- 自研向量数据库：已否决，第一版用全文搜索即可。

## 未完成事项

- 导入功能的错误恢复还没有完整测试。
- 性能目标：50,000 条消息时搜索应在 500ms 内返回。

## 目标与约束

- 目标：一个月内完成第一版。
- 约束：不得引入任何遥测或统计上报。
