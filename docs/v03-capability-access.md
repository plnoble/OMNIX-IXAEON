### 隔离与授权要点（S5 实施约束，来自计划 §7.3）

- 独立工作区（项目目录的副本或 git worktree），不碰用户主工作区；
- 固定程序+参数数组调用（`codex exec --cd <workspace> <prompt>`），不拼 shell；
- 不传 IXAEON 的任何密钥/令牌；任务背景经临时受限方式提供；
- 全局最多 1 个执行任务、默认 15 分钟上限、超时杀子进程树不杀用户进程；
- 默认不允许额外联网/安装/提交推送/发布（沙箱旗标落实；落实不了就标记受阻）。

## 2. 研究入口（S4 用）

### 现状：无已配置的搜索服务

| 方式                                | 事实                                                                                            |

| 公开网页/发布页/订阅源（HTTPS GET） | ✅ 可行——第一版围绕用户批准的明确来源运行（发布页、RSS/Atom、GitHub Releases 等），无需搜索服务 |

### 网络边界（S4 实施硬约束，来自计划 §6.2）

仅允许批准的 HTTPS 目标；禁 file:/回环/私网/链路本地/云元数据；DNS+连接双校验、重定向逐跳校验；无 Cookie/登录模拟/脚本执行；20s/2MiB/3 跳/并发上限；失败如实报告不绕过。

### 建议的第一版研究场景（真实可用，无需新费用）

用户从一句话创建关注主题（如某 GitHub 仓库的 Release、某文档页的更新）→
批准来源 URL → 每日检查 → 内容指纹去重 → 发现形成研究记录（含链接、摘录、
与目标关联）→ 应用内提醒。真实公开网络，零新增订阅。
