## 已实现（契约 1–4，源码 +117/−4 行）

- **`packages/relay/src/selfupdate.ts`**（+36）：`RESTART_EXIT_CODE = 75`；`relayCodeHash(root)`——`packages/relay/bin` 和 `packages/relay/src` 下所有文件按相对路径排序，逐个把「路径 + `\0` + 内容」喂进 sha256。`test/`、README 不算。
- **`packages/relay/src/index.ts`**（+2/−1）：导出 `relayCodeHash`、`RESTART_EXIT_CODE`。
- **`packages/relay/bin/relay-main.ts`**（+22）：看门人在 `IXAEON_RELAY_FOREVER=1` 且没设 `IXAEON_RELAY_CODE` 时，起来时对 `REPO_ROOT` 算一次指纹；之后每一轮在 `updateCodeCheckout`、`ensureDeps` 都成功之后、起 `once` 之前对 `relay-run` 再算一次；不一样就打「看门人自己的代码换了（旧前 8 位 → 新前 8 位），退出让 relay forever 重起」，`process.exitCode = 75` 后返回（不用 `process.exit`，锁在 `finally` 里照常放掉）。这一轮 `updateCodeCheckout` 有 note 或拉不下来 `origin/main` 时不比、照常起棒。
- **`packages/relay/bin/relay.mjs`**（+61/−2）：`relay forever` 在找 jiti **之前**分出去（自己不用 jiti、不读配置、不拿锁）。入口优先 `IXAEON_RELAY_CODE`，其次 `<工作目录根>/relay-run/packages/relay/bin/relay.mjs`（在才用），否则自己这份；`process.execPath <入口> run <其余参数>`、`cwd` 是入口所在仓库根、`stdio: 'inherit'`、环境多一个 `IXAEON_RELAY_FOREVER=1`。退出码 75 → 打「relay run 的代码换了，重起」马上再起（每次重新挑入口）；别的码用同一个码退出。10 分钟里第 6 次碰 75 → 「10 分钟里重起了 6 次，停下：看门人的代码和 relay-run 里的对不上」，退 1。
- **`packages/relay/README.md`**：命令表加 `relay forever`（推荐）；「不用重启就吃到新代码」补清「看门人自己那层要重起、forever 自动重起、10 分钟 6 次会停」；开机自启的 `schtasks` 命令改成 `forever`。
