## 已知缺口

- 本支的「项目」卡只显示空状态；真实项目卡片、折叠、状态切换在 K3b。两支没合齐之前，
  main 上的驾驶舱看不到项目。
- K2 把 relay 标成 `stale` 时没有填 `note`（`snapshot.ts` 只改了 status）。页面在 `note` 为空时
  回退显示「数据可能停了」，拿不到更具体的原因。这是 K2 的缺口，本单没改 K2。
- 设置页只保存路径，不校验它是不是 git 仓库；路径不对时驾驶舱顶部显示 K2 给的队列错误。
- 顶部「N 分钟前更新」按最旧 `readAt` 算；如果某个来源的 `readAt` 解析不了，就把它排除在外，
  全部解析不了时显示「更新时间未知」。
