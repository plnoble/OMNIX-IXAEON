**几处实现里定的（请整合方看）：**

1. **「调度器所在的这个仓库」用脚本位置现算**，不是 `process.cwd()`、也不是主检出：`REPO_ROOT = <relay-main.ts 往上三级>`。锁定测试要的正是「这份检出」（从工作目录里跑时就是那个工作目录）；真机乙的原样输出里能看到生成的开发者 `argv` 写的是 `…\L5\packages\relay\bin\dsh.mjs`。**没有**再用 `findSharedCheckout()`（那一版第一条测试就红了）。
2. **命令分发结构改成 `const main = async () => {…}; await main();`**：`init` 里有一次真的 `fetchMain`（HTTPS），而这台机器（Windows + Node 24 + jiti）上「发过 HTTPS 再 `process.exit`」退出时会崩（退出码 `0xC0000409`，L4 整合方修过同一个坑）。所以 `init` 走 `return`，`status`/`resume` 也从 `process.exit(0)` 改成 `return`，结尾统一 `process.exitCode = process.exitCode ?? 0`。行为没变，退出码还是 0。
3. **`_` 开头的说明键不写进生成的配置**（样例里的 `_开发说明_dsh` 是给人看的，写进真配置没意义）。
4. **init 顺手建 `<数据目录>/turns`**：Claude 那条 `--add-dir` 指着它，目录不存在的话那一棒会被拒；样例里没这一步。
5. **建 `relay-int` 之前先 `fetchMain`**（规格末尾整合方的补充）：拉不下来就打印「拉不下来 origin/main，建不了整合方的工作目录」、退出码 1（这一支的测试没覆盖它，真机乙这一轮也没有网络断的场景）。
