## 真机通过（甲：白名单的写法）

`node scripts/real/l2-claude-allowlist.mjs --probe <名字>`，每次一个临时 git 仓库、一次 Claude 真调用。一律 `--restricted --tools PowerShell --permission-prompts none`，没有用任何「跳过所有权限」的开关。输出已遮掉临时目录和账户名。

**真调用 5 次，花费合计约 $0.334**（`total_cost_usd`：0.14045 + 0.116896 + 0.032281 + 0.022522 + 0.021962）。没撞额度。上限 6 次，留了 1 次没用。

### 结论：两套白名单是同一串

冒号前缀和空格前缀**都放行**。推荐冒号写法（`git:*`），空格写法（`git *`）实测同样放行。整合方和开发要跑的命令是同一批（`git`、`node scripts/…`、`corepack pnpm`、`gh run`），所以两套用同一串：

```
Write Edit PowerShell(git:*) PowerShell(node:*) PowerShell(corepack:*) PowerShell(gh:*)
```

`Write Edit` 是 L0b 的结论带过来的：`--restricted` 之下模型有时用 shell 写文件，会被拒，要留文件工具。

放行的边界（这 5 次看到的）：

- 白名单认的是**命令开头**。只放行 `PowerShell(corepack:*)` 时，直接跑 `pnpm --version` 被拒；只放行 `PowerShell(git:*)` 时，`cmd /c git status --short` 被拒。
- 一条命令里用分号再接没放行的，**整条被拒**，不是只放行前半段：`git status --short; Remove-Item -LiteralPath note.txt` 在只放行 `git:*` 时整条进了 `permission_denials`，`note.txt` 还在。
- `Remove-Item` 单独一条被拒，文件还在。
- `gh run list --limit 1` 没有被权限拒绝，但这个临时仓库没有远程，它自己退出码 1（`no git remotes found`）。真仓库里有远程，这一条才跑得成。
