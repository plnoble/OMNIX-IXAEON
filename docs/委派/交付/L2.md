## 真机通过（甲：白名单的写法）

`node scripts/real/l2-claude-allowlist.mjs --probe <名字>`，每次一个临时 git 仓库、一次 Claude 真调用。一律 `--restricted --tools PowerShell --permission-prompts none`，没有用任何「跳过所有权限」的开关。输出已遮掉临时目录和账户名。

**真调用 5 次，花费合计约 $0.334**（`total_cost_usd`：0.14045 + 0.116896 + 0.032281 + 0.022522 + 0.021962）。没撞额度。上限 6 次，留了 1 次没用。

### 结论：两套白名单是同一串

冒号前缀和空格前缀**都放行**。推荐冒号写法（`git:*`），空格写法（`git *`）实测同样放行。整合方和开发要跑的命令是同一批（`git`、`node scripts/…`、`corepack pnpm`、`gh run`），所以两套用同一串：

```
Write Edit PowerShell(git:*) PowerShell(node:*) PowerShell(corepack:*) PowerShell(gh:*)
```

`Write Edit` 是 L0b 的结论带过来的：`--restricted` 之下模型有时用 shell 写文件，会被拒，要留文件工具。

放行的边界（这 5 次看到的）：

- 白名单认的是**命令开头**。只放行 `PowerShell(corepack:*)` 时，直接跑 `pnpm --version` 被拒；只放行 `PowerShell(git:*)` 时，`cmd /c git status --short` 被拒。
- 一条命令里用分号再接没放行的，**整条被拒**，不是只放行前半段：`git status --short; Remove-Item -LiteralPath note.txt` 在只放行 `git:*` 时整条进了 `permission_denials`，`note.txt` 还在。
- `Remove-Item` 单独一条被拒，文件还在。
- `gh run list --limit 1` 没有被权限拒绝，但这个临时仓库没有远程，它自己退出码 1（`no git remotes found`）。真仓库里有远程，这一条才跑得成。

## 为了让测试能跑，我定的接缝（请整合方看）

1. 测试一律 `import … from '../../src/index.js'`。`parseRoleOutput`（`src/output.ts`）、`fetchMain`（`src/git.ts`）、`dailyDue` / `dailyEvent`（`src/daily.ts`）都从 `index.ts` 再导出。
2. **`dailyEvent` 的 `done` 用的是记账里的 `taskId`，不是任务名。** 规格说「那些行的任务」，但记账行里没有任务原文，只有 `taskId`。要发任务名就得给记账加字段，或者发日报时再去队列里查。规格没写这一步，我按现有字段定的。
3. 「那一天」按 `startedAt` 的北京时间日历日算。`costUsd` 把当天各棒的 `usage.costUsd` 相加，缺的当 0；当天每棒都没有、或者一棒都没有，就不带 `costUsd`。
4. 飞书不从测试传进去。测试把合成的 `feishu.json` 放进 `IXAEON_RELAY_DIR` 指的临时目录，调度器自己 `loadFeishuTarget()`。没有这个文件就谁也不发。
5. 限频记在 `state.notify.sent` 里，跨 `once` 保留。`stopped` 的键沿用 L3：`stopped` 加 `taskId`，所以同一行 30 分钟内连停两次只发一条。
6. `fetchMain(cwd)` 回 `boolean`。开棒前它回 `false`：这次不开棒、不建 `turns/`、不加记账、不设 `stoppedReason`，`once` 退出码 0。核对时它回 `false`：停下，`violations` 里有 `verify-fetch-failed`，`stoppedReason` 里有「拉不下来」。
7. 重试的等待只在 `fetchMain` 那一条上量（≥ 6 秒）。没有放进 `once` 里量：现有实现一次 fetch 就返回，挂住的地址会让 git 自己超时（两分钟），量出来的不是这次要的 2 秒、5 秒。
8. 配置样例里的白名单占位符换成上面那一串。测试不钉 argv 的逐字内容，只钉条件 7 的三件事。
