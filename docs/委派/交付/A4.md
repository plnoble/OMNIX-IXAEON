# A4 切回来接着看还在写的回答——交付

日期：2026-10-01。分支：prep/A4。规格：docs/委派/A4-切回来接着看还在写的回答.md（A 档）。

## 已实现

改动集中在 `apps/desktop/src/renderer/src/pages/Ask.tsx`（对话页）+ 一个假模型测试钩：

- **2 秒同步 effect**（核心）：每 2 秒从库里拉当前对话；有 `status=streaming` 的
  助手消息就同步内容到气泡并显示跟进态（「正在回答…」，无阶段无秒数）；该消息
  不再 streaming 且之前在跟 → 重拉显示最终结果、清掉跟进态。切走再切回、页面
  重载后都能靠这条 effect 追上进度。发起页的 delta 实时处理器照旧工作（本页
  `waiting.current` 非 null 且非 joined 时 2s 同步跳过，不与 delta 竞争）。
- **假模型延迟钩**：`FakeProvider.chatDelayMs` + `IXAEON_TEST_MODEL_DELAY_MS`
  （仅 fake 模式生效），让「回答中」窗口拉长到可测的秒数。
- e2e：`apps/desktop/e2e/a4-follow-live-answer.spec.ts`（3 条，逐条对应条件 1/2、
  3、4；条件 5 由现有 d6/m2/smoke 套件照过）。
