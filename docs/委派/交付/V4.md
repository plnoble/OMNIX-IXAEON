### 钉住的接缝（要整合方过目）

- **`findLatestCodex(): Promise<{ exe: string; version: string } | null>`**（`packages/core/src/execution/verifySandbox.ts` 导出）。规格说「核心层导出一个拿它的办法（名字由实现定）」——总要有个名字，测试里按这个名字 import。**实现换成别的名字，改的是测试里那一处 import，条件一条不动。** `exe` 给执行器与沙箱共用同一份判断，`version` 就是契约 1 要的 `codexVersion`。
- `checkSandboxAuth(dataDir, env?)`、`requestSandboxAuth(dataDir)`、`resolveCodexLocator()` 的名字、参数、返回类型都不变（规格写死不改名的就这几个）。
- 契约 3.2 的三个超时值（20 / 15 / 120 秒）**没有断言**：实现用 `spawn*` 的 `options.timeout` 还是自己拿计时器是自由的，断言会把机制写死（这正是 P7、P8 复审时踩过的坑）。写在「已知缺口」里。
