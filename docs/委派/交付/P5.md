逐条对应：

1. 路径清空、授权变 `revoked`、审计 `project.folder_unbound` 一条、返回带授权 id。
2. 解除之后对话里「要做」、待办点「要做」、任务页「批准」都报 P4 那句，任务和待办不动。

4. 授权下的资料变成已撤销，提炼出的条目一条不少。
5. 另一个项目也绑着同一个文件夹（大小写、斜杠不同也算）：只清这个项目的路径，授权仍有效，`revokedPermissionId` 是 null，预览 `grant` 是 `kept_other_project`、资料数是 0。
6. 没有单独的有效授权、只有上级文件夹的授权：照样解除，上级那条不动，预览 `grant` 是 `none`。
7. 预览前后项目、授权、任务、审计都不变；要取消的、等接受的、资料数、`grant` 都对。
8. 项目不存在、没绑文件夹，两个接口都拒绝，什么都不变。
9. 重新绑定是一条新的有效授权，旧的还是 `revoked`；解除前等接受的任务这时接受，落出分支。
10. 解除调了 `invalidateContext`。
11. 绑了才有「解除绑定」；确认文字含项目名、路径，数字是 0 的行不出现，讲授权的那一行跟着 `grant` 变；取消确认不调解除；确认之后行变成「构想（未绑定目录）」和「绑定文件夹」，结果那句话如实。
