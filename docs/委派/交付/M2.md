# M2 模型管理——检测、勾选保存、各处从已保存的里选 交付

- 分支：prep/M2，基于 main d991fa1（A5 规格进队列之后）；档位 A
- 执行方：prep

## 已实现

- `packages/contracts/src/config.ts`：`model.savedModels: string[]`（默认空）与
  `model.modelsCheckedAt: string | null`（默认 null），zod 默认值，旧配置照常读得出来，不加迁移。
- `AppRuntime.saveModelSettings`（从 `ipc.ts` 迁入，便于验收测试钉住）：`savedModels`
  传入时以此为准并记 `modelsCheckedAt=现在`；不传时清单与检测时间保持原值。聊天模型
  变化仍走「丢引擎会话、下一问新进程」的既有逻辑。
- `ipc.ts`：`getSettings` 的 config 回传 `savedModels` / `modelsCheckedAt`；
  `saveModelSettings` 委托 runtime（`savedModels?: string[]` 进 IPC 契约）。
- 设置页（Settings.tsx）：
  - 「检测模型」后显示勾选清单：已保存的默认打勾、新出现的标「新」、已保存但上游
    没有的照样显示并标「上游已没有」（不自动删）；清单上方按名字筛选。
  - 「保存选择」把勾上的写进清单并记检测时间；没有手输模型名的入口。
  - 「模型名称」「聊天模型」都改成下拉框，只从已保存清单选；聊天模型多一项
    「跟随分析模型」；当前在用的模型不在清单里时照样显示并标「不在已保存清单」。
  - 重新检测只更新清单标记，不改当前在用的模型。Key 留空复用的既有行为未动。
