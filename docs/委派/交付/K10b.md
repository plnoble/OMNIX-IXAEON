## 已实现

`setRelayModel({ relayDir }, { role, value })`：

- 值必须在 `readRelayModels` 给出的 `options` 里；Codex 那一行按 `[A-Za-z0-9._-]+` 校验；
  不在就抛 `VALIDATION_FAILED`（`IXA0012`），**校验完才备份、才写**；
- DSH 三行：从 `roles.<角色>.argv` 的 `--patch` 找补丁，只改 `- id: agent-default-model` 段的
  `provider:` / `model:` 两行，缩进和行尾注释保留，其余字节不变；
- 整合方：在 `roles.integrator.argv` 里换 `--model <值>`（选「默认」= 去掉这一对），其他参数顺序不变；
- 审查：写 `review.codexModel`，空 = 删掉这个键（跟 Codex 自己的设置）；
- 改文件前在同目录留 `<原名>.bak-<YYYYMMDD-HHmmss>`；写入走「同目录临时文件 → 改名」，不留半截文件；
- IPC `setRelayModel(input)` 返回 `{ ok: true }`（contracts 类型、preload、主进程接好）；
- 报错只有固定短句，不带补丁 / 配置里的其他内容（密钥、网关地址、整段 argv）。

## 已知缺口

- **配置是 JSON 重写**：改整合方 / 审查时整份 `config.json` 用 2 空格 JSON 重新序列化，
  语义不变、字段顺序不变，但原文件的缩进 / 换行风格不再保留。补丁文件是逐行改的，逐字节不变。
- **备份按秒命名**：同一秒内连改两次，第二个备份会覆盖第一个（规格写死了这个文件名）。
- 整合方 `--model` 只做「一对」的增删，不校验这个模型 Claude 认不认；写进去由下一棒自己报错。
- 写回的三个角色（开发 / 替补审查 / 替补整合方）共用 `roles.<角色>.argv` 的 `--patch` 规则；
  K9a/K9b 并入前，替补两行没配，`setRelayModel` 对它们会报「这个角色的补丁文件读不懂」，
  界面也不会给没配的角色显示下拉框（K10c）。
