## 已实现

任务页「看改动」的只读比对：清单取执行报告的 `changedPaths`（normalizeRel、去重、排序），比副本里现在的文件和项目文件夹里现在的文件；行级 LCS 差异（+/-/空格前缀、3 行上下文、段间 `@@`、CRLF 与末尾换行不算差异）；每种「看不了」都有 note 和原因；授权判断与落地（landing.ts）同一条；`baseHashes` 基准漂移核对；files 最多 50、差异合计 200 000 字符预算。IPC `getCodingTaskChanges(id): Promise<TaskChanges>` 接在 contracts / main / preload 三处。

与规格不一样的地方：无。规格约束要用的现成导出（`normalizeRel`/`toLf`/`FORBIDDEN_NAME`/`isPathInside`）都用了；没动 `executor.ts`；没加迁移、没加 npm 依赖。
