## 已实现

- `packages/core/src/execution/executor.ts`（+18/-2）：
  - `electronRunAsNodeEnv(exe, execPath, versions)` 纯函数：被派生的可执行
    文件就是本进程自己且本进程是 Electron（versions.electron 有值）时返回
    `{ELECTRON_RUN_AS_NODE:'1'}`，否则空——普通 node 环境不注入；
  - `defaultCheck` 在派发验证子进程时注入该环境变量（在既有
    `minimalChildEnv()` 白名单之上，只加这一项，不放宽任何规则）；
  - `spawnArgv` 增加 `extraEnv` 参数（默认空，其他调用点行为不变）。
- `apps/desktop/src/main/appRuntime.ts`（+6/-2）：`stopServer(reason:
  'normal' | 'restore')`——正常退出写「本地服务已停止」，只有 restoreData
  路径写「本地服务已停止（数据恢复）」。
- 未改验证判定规则、未加可执行程序、无迁移。
