## 已实现

`packages/core/src/cockpit/relayModels.ts` 的 `readRelayModels({ relayDir })`：

- 从 `<relayDir>/config.json` 的 `roles.<角色>.argv` 找 `--patch` 后面那一项，按行读补丁文件；
- 在 `- id: llm-pi-ai` 的 `providers:` 下认网关、每个网关 `models:` 里认 `- id:`，选项是「网关 / 模型」对；
  只取这两种名字，`apiKeyEnv` / `baseURL` / `headers` 一律不读；开头的注释表不当依据；
- 在 `- id: agent-default-model` 段读当前 `provider` / `model`；
- 整合方读 `roles.integrator.argv` 里的 `--model`（没有 = 「默认」），审查读 `review.codexModel`
  （没有 = 「跟 Codex 自己的设置」）；替补审查读 `roles.reviewer`，替补整合方读 `roles.integratorSubstitute`，
  没配就 `configured: false`、`note: '没配'`；
- `--patch` 没有、出现多次、或后面不是值 → 该行 `configured: false`，不猜；
- IPC `getRelayModels()`（contracts 加类型、preload 暴露、主进程接 `readRelayModels`，`relayDir` 空串 =
  照 K2 走 `IXAEON_RELAY_DIR` / `~/.ixaeon/relay`）；`scripts/codex-review.mjs` 读 `review.codexModel`，
  有值给 `codex exec` 加 `-m <值>`，没值行为不变。

## 已知缺口

- **K2 快照的 `running` 里 `turn` 的 `role` / `taskId` 现在是 `null`**（K2 契约「turns/ 下的任何文件都不读内容」）。
  所以 K10b 的「现在在跑」只能显示第几棒和分钟数，角色、任务行、该角色模型都显示「—」。要真正填上，
  得改 K2 的只读范围或让 relay 写当前棒的角色/任务，那是另一单；本单不擅自改 K2 的锁定行为。
- 本支的 `readRelayModels` 每个角色都重新读一遍补丁（最多 3 次）；文件很小，没做缓存。选手册里的
  「下一棒生效」不校验 relay 是否正在跑那一棒。
- 规格说「补丁文件读不懂→ note 说明」：note 只有固定的「补丁文件读不懂」「补丁里读不出默认模型」两句话，
  不带路径或原文（隐私约束）。
- 规格「条件 7：卡片四行」和表格里 5 个角色（替补审查 / 替补整合方分两行）有出入；K10b 按表格做
  4 条一级行、替补两条子行，交付说明里会写清。
