## 已实现

关注方向的搜索额度按天恢复，累计额度的主题行为不变。五处：

1. `packages/contracts/src/entities.ts`：`ResearchTopic` 补上迁移 35 已加的两列 `daily_request_cap`（空 = 累计额度）、`request_budget_day`（上次恢复是哪天）。
2. `packages/core/src/research/researchStore.ts`：`toTopic` 读出这两列。
3. `packages/core/src/research/checker.ts`：每次检查开始前，`daily_request_cap` 有值且 `request_budget_day` 不是今天 → `request_cap` 恢复成 `daily_request_cap`、`request_budget_day` 写成今天。「今天」用 `localDay`（本地时区）。扣减逻辑不变。
4. `apps/desktop/src/main/appRuntime.ts`：`followWatchDirection` 在搜索已配置时写 `daily_request_cap = 3`、`request_budget_day = 今天`；没配置时不写（保持空）。
5. `apps/desktop/src/renderer/src/pages/Research.tsx`：额度文案写在各自的主题卡片里——按天的「今天还能搜 N 次（每天 3 次）」、用完「今天的搜索额度用完了，明天恢复」；累计的「还能搜 N 次（总额度）」、用完「搜索额度用完了，要继续请调高上限」。
