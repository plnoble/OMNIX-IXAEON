要点：

- `groundExcerptInSegment`：规范化（空白/零宽/引号）时保留原文位置；取摘录里出现在片段中的最长连续一段；返回原文切片。相邻规范化字符之间若夹了别的非空白字，不算连续。匹配若只是上一句句号经换行粘到下一段，剥掉该句号（整合方补的「两段都够长取最长」）。
- 提取：`isExcerptGroundedInSegment` 失败时先打捞；成功则改 `excerpt` 入库并计入 `salvaged`；失败仍走无效依据。全部打捞不到仍整份作废。
- 审计 `extract.excerpt_salvaged`：`sourceId`、`salvaged`、`dropped`。资料页分析说明在有打捞时显示「N 条依据按原文截短后保留」。
- `EXTRACT_SYSTEM_PROMPT` 加入规格原句（一个字未改）；`EXTRACT_PROMPT_VERSION = 'v6'`。
- `requeueFailedExtractions(db)`：只看每个来源最新一条 extract 任务；错误含「依据对不上原文」或「无效引用/依据」则新排一个；网络/429 不碰。资料页顶部「重新分析失败的资料（N 份）」，N=0 不显示。

未加迁移；未改 E2/E5。
