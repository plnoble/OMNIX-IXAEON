## 已实现

一个对话属于它创建时的项目；换项目要开新对话。三处改动：

1. `packages/core/src/storage/conversationStore.ts`：新增 `setProject`（空对话以第一问写回）与 `hasMessages`（锁不锁看有没有消息）。
2. `apps/desktop/src/main/appRuntime.ts`（`ask()`）：对话的 `project_id` 与调用方传来的 `projectId` 不一致（含 null 与某项目之间）→ `VALIDATION_FAILED`「这个对话属于另一个项目，换项目请开新对话」，什么都不发给模型；对话里还没有消息时以第一问为准并写回。本轮实际派发（`session.run`、预热接管、问答存档、再预热）都用校验后的 `effectiveProjectId`。
3. `apps/desktop/src/renderer/src/pages/Ask.tsx`：打开对话把下拉框切到它自己的项目；有消息 → 锁定 + 灰字「换项目请开新对话」；对话列表每项显示所属项目名（没有项目的写「全部项目」）。
