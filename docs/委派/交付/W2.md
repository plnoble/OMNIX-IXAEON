## 验收测试（v2 规格任务）

三条规格条件对应三份测试，开头注释逐条对应：

- `packages/core/test/acceptance/w2-translate.test.ts`：条件 1–7。`translateFindings(db, provider, topicId)` 与 `isMostlyChinese`（去掉空白后中文字符 `一-鿿` 占比 ≥ 30%）；模型用替身，截下每次 `chatStructured` 的 system 与 user。
  - 条件 1：英文发现写入 `title_zh`、`summary_zh`，再跑一次替身调用不增加。
  - 条件 2：中文为主的发现替身调用 0 次，两字段为空。
  - 条件 3：主题内部问题与要求各放一个合成标记，替身截下的请求里没有它们，只有标题和摘录。
  - 条件 4：模型抛错、以及 `provider` 为 null 时什么都不写且不报错；下次再试成功写入。
  - 条件 5：不在这一批的 id 忽略；`title_zh` 截到 40、`summary_zh` 截到 120；`title_zh` 为空白的那条不写。
  - 条件 6：15 条英文发现分两批，每批条数为 `[10, 5]`。
  - 条件 7：`checkNow` 返回的英文候选带 `titleZh` / `snippetZh`，中文候选不出现在任何请求里；翻译抛错时两项为空、候选照常返回，且断言替身确实被调用过（没尝试翻译的实现不算过）。
  - 另有一条：检查成功（抓到英文页面）后发现被翻译，请求里没有主题的内部问题。
- `apps/desktop/test/acceptance/w2-research-page.test.ts`：条件 8 的研究页。有中文的发现显示 `title_zh`、正文显示 `summary_zh`、`<details>` 里是原标题和原摘录、链接照旧打开原网址；没有中文的照旧显示原文且没有「原文」。搜索候选同样：`titleZh` / `snippetZh` 优先，原文可展开。
- `apps/desktop/test/acceptance/w2-overview-page.test.ts`：条件 8 的总览三块（「符合你要求的新发现」「最近的新发现」「研究里你标过值得行动」），标题有 `titleZh` 就显示中文，没有就显示原标题。

本机跑这三份：16 条全挂，失败原因都是功能还没写（`translateFindings is not a function`、`isMostlyChinese is not a function`、界面还显示原文）。
