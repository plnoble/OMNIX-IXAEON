## 验收测试（v2 规格任务）

新文件 `packages/relay/test/acceptance/l8-status-mask.test.ts`，3 个 `it`，逐条对应规格：

- 条件 1（输出里没有用户目录原文、有 `~`）：数据目录用 `IXAEON_RELAY_DIR` 指到
  `os.homedir()` 底下的 `mkdtemp` 目录；检查原文、正斜杠、JSON 转义三种写法都不出现，
  且输出里的 `dataDir` 以 `~` 开头。
- 条件 1（“所有内容”）：`ledger.jsonl` 里放一条 `doneLine` 带用户目录的合成记账，
  检查 status 打出来的记账行同样遮掉。
- 条件 2（只改打印，不改存的东西）：先写 `state.json` / `ledger.jsonl`，跑完 status 后
  两个文件与跑之前一字不差，存的路径还是原样。

1. **L4 冲突（本条转整合方的原因）**：L4 的三条锁定断言与 L8 验收条件互斥，见上。
2. 没有 Codex 审查结论、没有 CI、没有合并。
3. `maskHome` 只按 `os.homedir()` 遮；如果用户目录本身被写成带尾斜杠、8.3 短路径或
   大小写混写的别名，`status` 里也按同一写法原样打印，不保证能认出来。规格只要求
   遮 `os.homedir()` 的值，这一层没做。
