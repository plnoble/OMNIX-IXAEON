测试开头注释钉住的接缝：`AppRuntime.deleteProject(projectId)` 返回六字段结果；次序照契约 3（先照 P5 的 `unbindProjectFolder`、没绑的也照样取消在途任务并回报、再删项目、只删数据目录 `workspaces/` 之内的副本、删不掉的算 `copiesLeft`、有副本要清时记 `project.task_copies_removed { projectId, removed, left }`、最后 `invalidateContext`）；界面确认框文字照契约 4（第一段 = 原删除话加了副本句；绑着时才有的「这个项目绑着文件夹：」段，三种讲授权说法都以「- 」开头、数字 0 的行不出现），结果 `project-delete-result` 四种成分按实际接。
