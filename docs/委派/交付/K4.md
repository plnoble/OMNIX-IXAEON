## 整合方审测试（2026-10-31，接力第 64 棒）

**发现的问题（原样写对了实现也过不了）：**

1. 快照按同步调用，可合成 QuotaHub 和快照在同一个进程：同步等 HTTP 回答会卡住事件循环，服务回不了话，条件 2、5 怎么实现都红。→ `buildCockpitSnapshot` 改成返回 `Promise<CockpitSnapshot>`；K2 的 `k2-cockpit-snapshot`、`k2-cockpit-review`、`k2-cockpit-ipc` 改成 `await` 调用（同步、异步实现都能过，现在的同步实现上 21 条照样全绿）。
2. 活动测试的「现在」带毫秒，git 的提交时间只到秒，`lastCommitAt` 那句几乎永远差几百毫秒。→ 取整到秒。
3. `withGitTrace` 在快照异步之后会提前恢复 `GIT_TRACE`。→ 改成等快照出来再恢复。

**改严、补充**（变异检查第一轮 48 处 45 红，漏的 3 处补了测试后全红）：

- 请求经全局 `fetch` 发（条件 2 钉住），条件 3 拦 `fetch` 才证明得了没发请求；
