# 委派单 T3：待办页

任务来源：[三周任务单](../三周任务单.md) T3。档位：**A**（CI 绿即可由用户合并）。大小：中（≤250 行）。依赖：T1（已完成：迁移 33 + `TodoStore`）。

## 背景

「替你做事」这一段的入口：你要看得到它提了哪些事等你拍板、哪些在做、哪些做完了，并且能点回它是在哪次对话里提的。存取已经由整合方做好（`packages/core/src/storage/todoStore.ts`，状态见文件头注释），这一单只接 IPC 和界面。

## 契约（写死，照着实现，不改名）

1. `packages/contracts/src/ipc.ts` 的 `IxaIpcApi` 增加：

   ```ts
   /** T3：待办列表（带底下编码任务的实时状态）；不传 status = 全部 */
   listTodos(input?: { status?: TodoStatus[] }): Promise<TodoView[]>;
   addTodo(input: { title: string }): Promise<Todo>;
   acceptTodo(id: string): Promise<Todo>;
   rejectTodo(id: string): Promise<Todo>;
   completeTodo(id: string): Promise<Todo>;
   ```

   preload 用 `ixaeon:<方法名>` 通道；`ipc.ts` 的处理函数调用下面第 2 条的运行时方法。

2. `AppRuntime`：新增字段 `readonly todos: TodoStore`（与其它存取一样在 `create()` 与 `rebuildRuntimeServices()` 里建），和这几个方法——**T2b 会在 accept / reject 里接编码任务，现在先直接调存取**：

   ```ts
   listTodos(input?: { status?: TodoStatus[] }): TodoView[];
   addTodo(title: string): Todo;
   acceptTodo(id: string): Promise<Todo>;
   rejectTodo(id: string): Promise<Todo>;
   completeTodo(id: string): Todo;
   ```

3. 新页面 `apps/desktop/src/renderer/src/pages/Todos.tsx`，导出 `TodosPage({ onOpenConversation }: { onOpenConversation: (conversationId: string) => void })`：
   - 三块：`todo-section-proposed`「等你拍板」、`todo-section-accepted`「要做」、`todo-section-done`「已完成」（最近 30 条）。
   - 每行 `todo-<id>`：标题；来源（「AI 提的」/「你加的」）；有 `conversation_id` 的加一个「从对话来」按钮 `todo-open-<id>` → `onOpenConversation(conversation_id)`，没有的不画。
   - 等你拍板的：`todo-accept-<id>`「要做」、`todo-reject-<id>`「不做」。
   - 要做的：`todo-reject-<id>`「不做」；没有底下任务的加 `todo-complete-<id>`「做完了」（有底下编码任务的，完成跟着任务走，见 T2b）；底下是编码任务的显示 `todo-linked-<id>`「编码任务：<状态>」，状态中文照这张表：draft 草稿、waiting_approval 等批准、queued 排队中、running 进行中、pending_verify 等验证、pending_accept 等你验收、completed 已完成、failed 失败、cancelled 已取消、unknown 状态不明。
   - 加一条：输入框 `todo-add-input` + 按钮 `todo-add` → `api.addTodo({ title })`；空的不提交。
   - 任何操作之后重新 `api.listTodos()`；出错用 `ErrorBanner` 显示。
4. `App.tsx`：侧栏加「待办」（`data-testid="nav-todos"`，放在「聊天」下面），页面 `'todos'`。`onOpenConversation` 切到聊天页并打开那个对话：`AskPage` 加可选属性 `openConversationId?: string | null`，值变了就打开那个对话。
