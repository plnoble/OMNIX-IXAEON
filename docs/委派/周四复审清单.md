- origin（谁提的）与 confirmation（怎么确认的）两维正交；`confirm()` 是唯一的 proposed→active 门，
  聊天确认必须引用**真实存在、role=user、status=complete** 的消息（外键 + 代码双拦）。
- 任务完成/失败的**真值只从真实 Store 读**：coding_task 的 `pending_accept` 不算完成；
  `noteTaskFailed` 只记录真实 failed 的编码任务，非 failed 直接抛错——**没有为测试开的后门**。
- 失败不机械判 blocked：只写 watch/事件/提前复核，状态不动；blocked 的 `decided_by` 不许是 system。
- G1c 历史方案**只读**（六种写全拒）；重排单事务两阶段**正数**临时区，`BEFORE DELETE` 触发器证明不删重建，
