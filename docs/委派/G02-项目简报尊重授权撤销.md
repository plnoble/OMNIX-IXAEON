# 规格 G02：撤销读取授权后，项目简报不再取用那份资料

档位：**B**（权限与隐私）。大小：小（≤120 行源码）。依赖：无。来源：[全局审核 2026-09-20](交付/全局审核-2026-09-20.md) G02。
v2 规格：先把验收条件写成测试（`packages/core/test/acceptance/g02-*.test.ts`），**先只推测试**等整合方看过并锁定，再实现。

## 要什么

P3 的项目简报（`packages/core/src/runtime/projectBrief.ts`）只看「有没有 `project_snapshot` 来源」就跑 git，并直接读编码代理会话的原文拼进发给 Hermes 的提示词——**没有检查这些来源的授权还在不在**。用户在来源页撤销了读取授权，以为不许读了，这条路还在取用。整合方复审 P3 时漏了这一条。

## 契约

1. **编码代理会话**：只取授权仍有效的来源（与其它读取入口同一把尺子：`isSourceAuthorized`，或在查询里连 `permissions` 取 `status = 'active'`）。
2. **最近提交**：这个项目的 `project_snapshot` 来源授权仍有效，**并且**该授权覆盖项目当前的根目录（`isPathInside(授权路径, 根目录)`）时才跑 git。快照授权被撤销、或项目换了根目录跑到授权范围外 → 不跑。已有快照不能充当永久授权。
3. 编码任务是 IXAEON 自己的本地数据，照带。

## 约束

- 不改简报的格式、截断规则和计数含义（计数照旧是实际带上的条数）。
- 不加迁移。

## 验收条件

1. 两个编码代理会话来源，撤销其中一个的授权：简报里没有它的标题和最后一句话，另一个照常；`counts.sessions` 为 1。
2. 撤销 `project_snapshot` 来源的授权：不跑 git（git 替身调用 0 次），简报里没有提交块；会话、任务照常。
3. 项目根目录改到快照授权范围之外：不跑 git。
4. 授权都有效时：和 P3 原来的行为一致（P3 的锁定验收照过）。

## 真机检查

跑一次 `scripts/real/p3-hermes-brief.ts`，确认正常路径没有退化，贴输出。
