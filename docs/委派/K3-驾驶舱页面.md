# 规格 K3：驾驶舱页面

档位：**A**（界面，只读展示）。大小：中（≤300 行源码；超了就把"项目"区拆成 K3b）。依赖：K2。
v2 规格：先写测试（`apps/desktop/test/acceptance/k3-*.test.ts`，用模拟的快照），和实现一起交。

## 要什么

桌面版新增"驾驶舱"页，放在导航第一位，应用启动后默认打开。

从上到下：

1. **顶部**：标题，加上"N 分钟前更新"（取各来源 `readAt` 里最旧的那个）。任何来源是 `stale / missing / error` → 这一行变红，并列出是哪个来源、原因（`note`）。
2. **三个数字**：等你处理（`attention` 条数）、正在运行（`running` 里 `relay` 和 `turn` 的条数）、今天完成（`today.finishedTurns`）。额度数字留位置给 K4。
3. **等你处理**：每条显示类型标签、项目、一句话、发生时间。`relay_down`、`turn_unfinished`、`relay_stale` 用红色。
4. **正在运行**：角色、任务号、已跑多少分钟；额度暂停中的角色显示"额度暂停到 HH:MM"。
5. **项目**：
   - "进行中"展开成卡片：名称、描述、当前状态；
   - "暂缓""放弃"各折叠成一行，显示数量（如"暂缓（10）"），点开才展开；
   - 卡片上可以切换状态，复用项目页现有的 `updateProjectStatus`。
6. **最近动态**：最多 20 条时间线：时间、角色、任务号、结果（完成 / 失败 / 超时 / 额度）。

每 60 秒自动刷新一次，另有手动刷新按钮。数据从 K2 的 IPC `getCockpitSnapshot` 拿（`window` 上 preload 暴露的那个 api），不走 HTTP。

**设置页**加一项「IXAEON 仓库路径」（存 `cockpit.ixaeon_repo`，K2 读队列用）：只是一个文本框加保存，空着就表示不读队列，驾驶舱顶部那一行会写「队列：没设仓库路径」。

## 约束

- 除了沿用现有的项目状态切换，不加任何写操作。
- 不加迁移，不改 K2 的快照结构。
- 空数据时，各区显示空状态文字，比如"现在没有在跑的任务"，不报错。
- 时间显示为本地时间；"N 分钟前"每次刷新时重算。

## 验收条件

1. 模拟快照（`attention` 2 条、`running` 1 条、`today.finishedTurns` 5）→ 三个数字分别是 2、1、5，两个列表条数对。
2. `sources.relay.status = 'stale'` → 顶部红色提示里写着 relay 和它的 note；全部 `ok` 时没有红色提示。
3. 项目各组 3 / 10 / 1 个 → "进行中"显示 3 张卡片，"暂缓（10）""放弃（1）"默认折叠，点开后分别显示 10 张和 1 张。
4. 定时器 60 秒触发一次接口调用（假时钟）。
5. 快照为空 → 各区显示空状态文字，没有报错。
6. 导航第一项是"驾驶舱"，应用启动后的默认页是驾驶舱（`App.tsx` 现在默认是 `overview`，总览照旧留在导航里）。
7. 设置页填了仓库路径、保存 → `cockpit.ixaeon_repo` 存上了；清空保存 → 设置项变空。

## 真机检查

设 `IXAEON_DATA_DIR=<临时目录>`、`IXAEON_RELAY_DIR=<合成 relay 目录>` 启动应用：
1. 截图驾驶舱；
2. 把合成 `lock.json` 的 pid 改成不存在的值，等它刷新后再截图，应看到红色"调度器进程不在了"。

两张截图贴进交付说明。
