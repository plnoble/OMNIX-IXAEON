# 委派单 A3：记忆桥查到的记忆，出处标签与聊天注入一致

任务来源：[三周任务单](../三周任务单.md) A3。档位：**A**（CI 绿即可由用户合并）。大小：小（≤40 行）。

## 背景

E3 之后，聊天注入会把 AI 在对话里给的建议标成「AI 当时的建议，不是用户的决定」，采纳过的标成「用户采纳的 AI 建议」，并说明这些是当时的看法、不是定论。但记忆桥的 `search_memory`（`apps/desktop/src/main/appRuntime.ts` 的 `hermesTool`）自己拼标签，只分「用户指定 / 系统推断」。开着记忆桥时，Hermes 查到 AI 的建议，会把它当成系统对用户的推断。

## 契约（写死）

1. `search_memory` 返回的每条 `origin` 改用 core 导出的 `memoryOriginTag(item)`（已从 `@ixaeon/core` 导出），与聊天注入同一套标签。
2. 查到的记忆里有 AI 建议（`saidBy === 'ai'` 或 `origin === 'assistant_suggestion'`）时，返回体多一个字段 `adviceNote: string`，内容说明那是当时的看法、不是定论（要含「不是定论」四个字）；没有 AI 建议时不带这个字段。

## 验收（锁定，执行方不改）

- `node scripts/acceptance.mjs run A3` 全过（`apps/desktop/test/acceptance/a3-bridge-origin-tag.test.ts`）；
- `node scripts/verify.mjs` 全过。

## 不要做

- 不改记忆桥的权限、令牌、工具名单；
- 不改锁定的验收测试。

## 交付

改动文件与行数；验收与 verify 的输出。推送你的分支，**不要自己合并**。
