# 委派队列

执行方（Grok、Codex 等）按顺序领活，不用等人派。怎么领、做完的标准、怎么合并，见 [AGENTS.md](../../AGENTS.md)「委派流水线」。

规则摘要：

- 领第一个「待领」且依赖都已完成的任务，把状态改成「进行中（你的名字）」并提交这一行的改动；
- 每个任务在自己的分支和工作目录里做（`git worktree add ../ixaeon-<任务号> -b <你的名字>/<任务号>`）；
- 做完的标准：`node scripts/acceptance.mjs run <任务号>` 全过、`node scripts/verify.mjs` 全过、推送后 GitHub 上的 verify 检查是绿的；
- **锁定的验收测试不许改**（指纹在 [锁定验收.json](锁定验收.json)）。觉得测试本身有错：停下，在交付说明里写清楚。
