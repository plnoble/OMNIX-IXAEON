# 规格 U6：报错条去掉 Electron 加的那串英文前缀

档位：**A**（只改界面上把错误转成字的那一个函数；主进程抛什么、日志记什么都不变）。大小：小（≤30 行源码）。依赖：无。来源：P5 真机检查第 4 步的输出（2026-10-08）。整合方查出来的，不是用户提的。

v2 规格：验收条件写成测试（`apps/desktop/test/acceptance/u6-*.test.ts`），测试和实现一起交，Codex 审查时核对有没有漏条件。

## 要什么

应用里任何一步出错，页面上方的报错条现在是这样的（P5 真机输出原样）：

> Error invoking remote method 'ixaeon:approveCodingTask': Error: IXA0012 这个项目还没绑定文件夹：先在项目页点「绑定文件夹」，再派编码任务。

有用的只有最后那一句，前面一串是 Electron 加的。

查下来是这样：主进程抛出来的错统一成了「错误码 + 空格 + 消息」（`apps/desktop/src/main/ipc.ts` 末尾的 `wrap`），界面上把错误转成字的函数 `errMsg`（`apps/desktop/src/renderer/src/api.ts`）也只认以错误码开头的写法。可是 Electron 把错误转给界面时，在前面加了 `Error invoking remote method '<接口名>': Error: `，于是 `errMsg` 一次也没认出来过——所有页面的报错条都带着这一串，92 处调用无一例外。

这一单：`errMsg` 先把这一段去掉，再照原来的办法认。只改这一个函数。

## 契约（接口写死，不改名、不加字段）

`errMsg(err: unknown): string`，签名不变。按这个次序：

1. 取原文：`err` 是 `Error` 就取它的 `message`，不是就 `String(err)`。
2. 原文**开头**是 `Error invoking remote method '<接口名>': ` 的，去掉这一段。只认开头，只去一次；`<接口名>` 是单引号里不含单引号的任意字。
3. 接着开头是 `Error: ` 的，去掉。只去一次。别的类名（`TypeError: ` 之类）不去——那是意外的错，类名有用。
4. 剩下的以错误码开头（`IXA` 加四位数字，后面跟空白）→ 返回 `<错误码>：<消息>`。这是原来就有的写法，不变；消息里有换行的照留。
5. 不以错误码开头 → 剩下的原样返回。

另外：

- **错误码留着**（`IXA0012：……`）。这是这个函数原来就想显示的样子，也方便把报错原样转给整合方。要不要连错误码也不显示，这一单不定。
- **主进程不动**：`wrap`、各处抛错的话、日志都不改。`apps/desktop/src/main/rendererDiagnostics.ts` 的 `errorSignature` 认的仍然是带前缀的原文（日志里要留着是哪个接口出的错），不受影响。
- 各页面调 `errMsg` 的地方不动。

## 约束

- 源码只改 `apps/desktop/src/renderer/src/api.ts` 里的 `errMsg`。
- 不加 IPC，不加迁移，不改主进程。
- 锁定的验收测试、端到端测试里要是有哪条认的是带前缀的旧写法：停下，写进交付说明。（整合方查过一遍：页面类的锁定测试都把 `errMsg` 换成了自己的替身；端到端和各套回归里没有认 `Error invoking` 的。）

## 验收条件

1. 带前缀、带错误码：上面那一句 → `IXA0012：这个项目还没绑定文件夹：先在项目页点「绑定文件夹」，再派编码任务。`
2. 没有前缀的 `IXA0003 消息`（给 `Error` 和直接给字符串两种）→ `IXA0003：消息`，和现在一样。
3. 带前缀、不带错误码：`Error invoking remote method 'ixaeon:x': TypeError: boom` → `TypeError: boom`；`Error invoking remote method 'ixaeon:x': Error: 普通的话` → `普通的话`。
4. 前缀只认开头：消息中间出现 `Error invoking remote method '…': ` 的，那一段不动。`Error: ` 只去一次：`Error invoking remote method 'a': Error: Error: x` → `Error: x`。
5. 消息里有换行：换行后面的内容都在。
6. 不是 `Error` 的值：字符串照上面的规则；`null`、`undefined`、普通对象不抛错，返回 `String(值)`。
7. 界面（任务页）：接口照 Electron 的写法拒绝时，报错条（`data-testid="error-banner"`）里的字是条件 1 那样，不含 `Error invoking remote method`，不含 `ixaeon:`。这一条要用**真的** `errMsg`——别的页面测试是把它换成替身的，这里不能换（只把 `api` 换掉，`errMsg` 用模块里原来的）。

## 真机检查

`scripts/real/u6-error-banner.mjs`，照 `scripts/real/p5-unbind-folder.mjs` 的做法（临时数据目录、随机端口、`IXAEON_EMBED_MODEL=none`、`IXAEON_CODEX_EXE=none`、打印时遮掉临时目录）：

1. 新建一个不绑文件夹的项目；任务页给它建一个草案，点「批准并排队」。
2. 打印报错条里的字。

报错条里有 `Error invoking remote method`，或者不是以 `IXA0012：` 开头，就以非零码退出。脚本自己出错也要以非零码退出。输出原样贴进交付说明。
