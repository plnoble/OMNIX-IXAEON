# 规格 S3a：编码代理会话的选择导入——核心与 IPC

档位：**B**（批量读本机文件、决定哪些内容发给模型分析）。大小：中（≤300 行）。依赖：S1、S2（已完成）。界面是 S3b。
v2 规格：你先把验收条件写成测试（`packages/core/test/acceptance/s3a-*.test.ts`，需要 IPC 的放 `apps/desktop/test/acceptance/`），**先只推测试**等整合方看过并锁定，再实现。

## 要什么

用户要把自己和 Claude Code、Codex 的会话导进来（场景一：让 IXAEON 知道在开发什么、做到哪了）。现在只能在文件对话框里一个个挑 `.jsonl`，而且看不出哪个是哪个；整个文件夹导入又会把几十个会话全部发给模型分析（本机 Claude Code 13 个会话约 120 万字，Codex 33 个约 120 万字）。

改成：选一个文件夹 → 列出里面认得出的会话（是什么、在哪个项目、多新、导过没有）→ 用户勾选 → 只导勾选的，导之前告诉他大概要发给模型分析多少字。

## 契约

1. 列出：IPC `listAgentSessions({ ticket })`。`ticket` 是 `pickFiles('directory')` 给的一次性票据；IPC 处理函数消费票据、给这个目录建 folder 授权（和现在的文件夹导入一样），再调 `runtime.listAgentSessions({ root, permissionId })`，返回 `{ listId, sessions, unrecognizedCount, subagentCount }`，编号 `id` 是数字。核心层的扫描放在 `ImportService.previewAgentSessions(root)`（锁定测试按这两个名字调）。递归找 `.jsonl`（最多 2000 个），每个只读**开头（最多 20 个非空行，且最多 256KB）和末尾 256KB**，不整份读——开头也要有字节上限，会话开头就可能有一条几 MB 的工具输出：
   - 认不出的不列，只报个数；Codex 子代理会话（`isCodexSubagentSession`）不列，只报个数；
   - 每项：编号（主进程生成）、工具（claude_code / codex）、标题（Claude Code：末尾那段里最后一个 custom-title，没有就最后一个 ai-title，再没有就开头里第一句用户的话；Codex：开头里第一句用户的话，按 S2 的规则去掉注入的段；都没有就用文件名）、工作目录 `cwd`、按 `cwd` 匹配到的项目（规则同 S1）、文件修改时间、大小、状态（新 / 已导入 / 有更新：按 provider + externalId 找已有来源，找到且文件修改时间晚于来源的导入时间算「有更新」）。
   - 主进程把这次清单（编号 → 路径、授权）存在内存里，给一个清单号；过期（30 分钟）或应用重启就作废。
2. 估算：`estimateAgentSessions({ listId, ids })`：完整解析选中的会话（S1/S2 的解析器），返回每个和合计的「你说的字数」「AI 回答字数」。
3. 导入：`importAgentSessions({ listId, ids, projectId })`：只认清单里的编号；逐个走现有的 `importFile`（带这次的 folder 授权），逐个失败隔离；返回新导入 / 未变化 / 失败，并把新导入的排进分析队列（同现有导入）。
4. **渲染层不传路径**，只传清单号和编号；不在清单里的编号、过期的清单号 → `VALIDATION_FAILED`。

## 约束

- 不加迁移；解析规则只用 S1/S2 的，不另写一套。
- 列出时不整份读文件；估算和导入会整份解析，单次调用卡住主进程超过 3 秒的，在交付说明里写明实测多久（本机最大的会话 1.5GB，解析 2.6 秒）。
- 列出、估算都不把任何内容发给模型或网络。

## 验收条件

1. 合成文件夹里有 2 个 Claude Code 会话、1 个 Codex 会话、1 个 Codex 子代理会话、1 个无关的 `.jsonl`：列出 3 个；子代理 1 个、认不出 1 个只报个数。
2. 标题：Claude Code 取最后一次改的名字；Codex 取第一句用户的话，注入的 AGENTS.md、环境说明不会当成标题。
3. 状态：导入其中一个后再列，它是「已导入」；再往那个文件追加一轮对话（并更新修改时间）后再列，它是「有更新」。
4. 只导勾选的，别的不动；返回的计数对；新导入的进了分析队列。
5. 编号不在清单里、清单号过期或编造：拒绝，什么都不导。
6. 估算的字数等于解析器解析出的你说的、AI 回答的字数之和。
7. 列出一个大文件（合成一个 20MB、中间都是工具输出的会话）时，只读了开头和末尾：用计时或读文件的桩验证不是整份读。

## 真机检查
