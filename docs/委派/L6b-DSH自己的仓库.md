# 规格 L6b：DSH 自己的仓库（沙箱里提交得了）

档位：**B**（改开发角色的工作目录布局；改替推的检查）。大小：小（约 100 行源码）。依赖：L6 ✅。来源：L6 真机检查乙（[交付说明](交付/L6.md)）：开发的工作目录都是共用仓库的分身（`git worktree`），它们的 `.git` 在共用检出目录那边、不在 DSH 的工作目录里；DSH 的沙箱只许它跑的命令写自己的工作目录，git 提交要写 `.git`，所以提交不了。

v2 规格：先把验收条件写成测试（`packages/relay/test/acceptance/l6b-*.test.ts`），**先只推测试**，整合方锁定后再写实现。

## 要什么

给 DSH 一套它自己的：开发的工作目录根换成 `<工作目录根>/dsh`，里面一份它自己的克隆 `repo`（`.git` 在里面），它照 AGENTS.md 建的任务工作目录也落在这底下。这样 git 只写 DSH 自己的目录。推送照 L6 由调度器替它做，推到同一个 GitHub 仓库。**不放开任何权限。**

## 契约（接口写死，不改名、不加字段）

1. **启动器**（`packages/relay/bin/dsh.mjs`）：环境里没有 `IXAEON_WORKTREES` 时，设成它自己的当前目录（调度器起开发时的 `cwd`）；已经有就不动。这样 DSH 里跑的 `scripts/worktree.mjs` 把工作目录建在它自己的根下面。
2. **替推的检查**（`src/push.ts`，改 L6 契约第 4 条的「同一个仓库」那一道）：`dir` 满足下面**任意一条**就算过：
   - 照旧：`dir` 的 `--git-common-dir` 和调度器所在仓库的一样；
   - 新加：`dir` 的 `--git-common-dir` 在这个角色的 `cwd` 里面，**并且** `dir` 的 `origin` 地址和调度器所在仓库的 `origin` 地址一样（`git remote get-url origin`，比较时去掉末尾的 `/` 和 `.git`，Windows 上不分大小写）。
     别的几道（在 `cwd` 里、远端分支只许 `main` 和 `dev/`、分支名不许 `+ : 空格`、不许以 `-` 开头）照旧。
3. **交代**：`pushByRelay` 为真的角色，L6 那一段后面再加一句（逐字，`<cwd>` 换成这个角色 `cwd` 的绝对路径）：

   > 你的仓库是 <cwd>/repo：AGENTS.md 里说的「共用检出目录」换成它；工作目录照 AGENTS.md 用 node scripts/worktree.mjs 建，会落在 <cwd> 下面。

4. **`relay init`**：开发的 `cwd` 改成 `<工作目录根>/dsh`。`<工作目录根>/dsh/repo` 不存在就从调度器所在的这份检出**本地克隆**（`git clone <仓库根> <它>`，不走网络），再把它的 `origin` 改成调度器所在仓库的 `origin` 地址（`git remote set-url origin <地址>`）；已经存在就不动。克隆失败：打印「建不了开发的仓库：<原因>」、退出码 1、不写配置。
5. **配置检查**照旧（开发的 `cwd` 不许包着数据目录，`<工作目录根>/dsh` 本来就不包）。

## 约束

- 测试用临时目录和临时 git 仓库，不调真模型、不连 GitHub。`relay init` 的测试会本地克隆一份本仓库到临时目录（克隆，不是工作目录，收尾直接删目录）。
- L6 的锁定测试里有一条（`cwd` 里另外 `git init` 的仓库 → 拒）给那份仓库配的 `origin` 和调度器的一样，照新规则会被放行——整合方会把那一条改成给它配一个**不一样**的 `origin`，再重锁 L6。别的 L1–L6 锁定测试不改，要和这一单一起过。
- 不改用户本机的数据目录和 `relay-int`；用户本机的配置由整合方并入之后重新生成。

## 验收条件

1. **启动器**：替身打印收到的 `IXAEON_WORKTREES` 和当前目录：没有设时 → 等于启动器起它时的当前目录；原来设了 `X` → 还是 `X`。
2. **替推放行**：开发的 `cwd` 里一份独立克隆（`.git` 在里面），`origin` 和调度器的一样 → 替推成功（裸仓库上有了那个分支）。
3. **替推拒绝**：`cwd` 里一份独立克隆，`origin` 指到另一个裸仓库 → 一条都不推、停下、原因里有它的目录；`origin` 地址只差末尾的 `.git` 或 `/` → 算一样、放行。
4. **交代**：`pushByRelay` 角色的交代里有第 3 条那句，`<cwd>` 换成了真的路径；别的角色没有。
5. **`relay init`**：开发 `cwd` 是 `<IXAEON_WORKTREES>/dsh`；`<IXAEON_WORKTREES>/dsh/repo` 是一个 git 仓库、`.git` 在它里面（`--git-common-dir` 在它下面）、`origin` 地址和本仓库的一样；第二次跑（配置已经在）不动它。
