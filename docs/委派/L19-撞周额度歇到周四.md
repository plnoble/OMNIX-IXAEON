# 委派单 L19：撞了 Claude 的周额度就歇到周四凌晨 4 点

档位：**A**（只改调度器歇多久的算法；不放开权限、没有新的外发）。大小：小（约 40 行源码）。依赖：无。来源：接力第 29 棒（规划棒），[三周任务单](../三周任务单.md)「接下来一周」第 3 件。

## 要什么

角色撞额度现在一律歇 `quotaPauseMinutes`（整合方 120 分钟）。Claude 的**周额度**用完的话，要等到每周四凌晨 4 点（北京时间）刷新，这期间每两小时白起一次 Claude、白发一次通知。改成：配置里给角色多一个 `weeklyQuotaPatterns`，输出里认出其中一条，就歇到**下一个北京时间周四 04:00**；别的额度照旧。

## 为什么

- 三周任务单「省着用」：Claude 每周四凌晨 4 点刷新（用户 10-20 说的）。
- 周额度说的是哪几句话，**我们没见过**：L0、L0b、L2 的交付说明里只记到过会话额度（`"api_error":"usage_limit_reached"`、`"result":"You've hit your session limit · resets 3:10am (Asia/Shanghai)"`），没撞过周额度。所以不往代码里写猜的字样，写成配置项，用户（或整合方）第一次真撞上时从 `turns/<第几棒>/stdout.txt` 里抄过来填上。

## 契约（接口写死）

1. `RoleConfig`（`packages/relay/src/types.ts`）加一个可选字段 `weeklyQuotaPatterns?: string[]`。没有或空数组 → 行为和现在一字不差。
2. 新文件 `packages/relay/src/weekly.ts`，导出 `nextWeeklyReset(now: Date): Date`：返回严格晚于 `now` 的、最近的一个北京时间（UTC+8，不考虑夏令时）周四 04:00:00.000。例：北京周四 03:59 → 当天 04:00；北京周四 04:00 整 → 下周四 04:00；北京周三 23:00 → 第二天 04:00。从 `src/index.ts` 导出。
3. `run-turn.ts` 认额度那一处：在同一份 `hay`（已经去掉 DSH 工具结果和思考的那份、小写）里，`weeklyQuotaPatterns` 有任何一条（去首尾空白后非空、不分大小写）出现 →
   - `quotaHit` 为 `true`（不管 `quotaPatterns` 有没有对上）；
   - `state.pausedUntil[<角色>]` = `nextWeeklyReset(new Date())` 的 ISO 串（不再加 `quotaPauseMinutes`）。
   只有 `quotaPatterns` 对上时照现在的算法。
4. `RunResult`、记账、通知的字段都不加；通知里「歇到几点」用的就是 `pausedUntil`，自然跟着变。
5. `checkConfig`：`weeklyQuotaPatterns` 有这个字段时必须是字符串数组，否则拒绝启动，原因写 `<角色> 的 weeklyQuotaPatterns 必须是字符串数组`。

## 约束

- 只改 `packages/relay/`。`config.example.json` 不加这个字段（`relay init` 照它生成配置，L5、L6b 的锁定测试照着它的形状；生成配置跟上新字段是 L20 的事）。README 的配置说明里加一行：这个字段干什么、默认没有、第一次撞上周额度时从哪儿抄字样。
- 已锁定的测试一个字不改。
- 不解析输出里的「resets 3:10am」这类时间（会话额度怎么歇不在这一单里）。

## 验收

新测试 `packages/relay/test/acceptance/l19-weekly-quota.test.ts`：

1. `nextWeeklyReset`：契约第 2 条的三个例子；北京周四 04:00:00.001 → 下周四；北京周日中午 → 接下来那个周四；返回值都是 UTC 的周三 20:00:00.000；返回值减 `now` 都在 (0, 7 天] 里。
2. 替身角色输出里带 `weeklyQuotaPatterns` 里的字样（大小写和配置里不一样）→ `quotaHit` 为 `true`，`pausedUntil` 是一个周三 20:00:00.000Z、晚于现在、不超过 7 天。
3. 同时对上 `quotaPatterns` 和 `weeklyQuotaPatterns` → 按周额度歇。
4. 只对上 `quotaPatterns` → `pausedUntil` 约等于现在 + `quotaPauseMinutes`（和现在一样）。
5. 周额度字样只出现在 DSH 的工具结果里（`agentNoise` 去掉的那种行）→ 不算撞额度。
6. `weeklyQuotaPatterns` 是 `[""]` 或 `["  "]` → 什么都不认；是字符串（不是数组）或数组里有数字 → `checkConfig` 拒绝，原因照契约第 5 条。
