# 规格 D1：聊天里说「把 X 做了」，生成编码任务草案

档位：**B**（给聊天模型开新工具、改发给模型的约定）。大小：中（≤250 行源码）。依赖：迁移 38（整合方已加 `coding_tasks.acceptance_json`）。来源：场景一（用户 2026-09-26 选定，09-27 定了落地方式与验收把关）。
v2 规格：先把验收条件写成测试（`apps/desktop/test/acceptance/d1-*.test.ts`，核心部分可放 `packages/core/test/acceptance/`），**先只推测试**等整合方看过并锁定，再实现。

## 要什么

场景一的第一步。现在聊天走 Hermes，Hermes 只拿得到记忆桥的三个工具（`search_memory`、`get_evidence`、`record_observation`），调不到 `propose_task`——T2b 的交付里写过「真 Hermes 聊天轮拿不到 propose_task（设计边界）」。所以在真实应用里说「把 X 做了」，建不出编码任务。

给记忆桥加一个工具 `propose_coding_task`：聊天模型把「要做什么」和「怎么算做完」写成草案。草案走 T2b 已有的路：挂在这一轮回答下面成为待办卡，用户点「要做」才会开工（D3 接着自动派发）。

## 契约

1. `HERMES_BRIDGE_TOOLS` 加 `propose_coding_task`（`packages/contracts/src/mcp.ts`），Hermes 用的 MCP 服务（`apps/mcp`）同步声明它；本地服务的 `/api/hermes/tool` 照旧按名单放行。
2. 参数：`goal`（1–2000 字）、`acceptance`（1–8 条，每条 1–200 字：一句能写成测试的「怎么算做完」）、`scope`（可选，项目内的相对路径或目录；缺省为整个项目）。
3. **项目不由模型选**：看当前正在回答的提问（`activeAskRuns`）。恰好一个正在回答、且它的对话属于某个项目 → 用这个项目；没有正在回答的、或那个对话不属于项目 → 报错「编码任务只能在项目对话里提（先选项目、开新对话）」；同时有多个项目对话在回答 → 报错「同时有多个项目对话在回答，分不清是哪个，请稍后再提」。参数里带的项目一律不认。
4. 建出的任务：状态照 T2b 的草案；`origin_run_id` = 那一轮的 runId（桥接调用不在那一轮的异步上下文里，必须显式写）；`acceptance_json` 存验收条件；验证命令先留空（验收测试先行由 D2 做，现在回报里如实写「还没有独立验收」）；`scope` 里越出项目（`..`、绝对路径）的拒绝。
5. 返回给模型：`{ taskId, status: 'draft', project: 项目名, note: '草案已建：用户在这条回答下面点「要做」才会开工；不要说已经做完' }`。记审计 `hermes.propose_coding_task`（任务 id、项目 id）。
6. 给模型的约定（`session.ts` 里记忆桥开着时附带的那段）加一句：用户要在当前项目里做一件开发的事（写代码、修 bug、加功能）时，调用 `mcp__ixaeon__propose_coding_task` 提草案，写清目标和能验收的条件；草案要用户点「要做」才开工，不要自己说已经做完。桥关着时不提这个工具。

## 约束

- 草案不批准、不派发、不跑任何命令；外发给编码代理要等用户点「要做」。
- 不改 T2b 的待办卡与「拍板」规则、不改 G04 的归属规则。
- 不加迁移。

## 验收条件

1. 项目对话正在回答时，桥接调用 `propose_coding_task` → 建出草案：项目是这个对话的项目，`origin_run_id` 是这一轮，`acceptance_json` 是给的条件；这一轮回答下面出现它的待办卡。
2. 没有正在回答的提问、或正在回答的是不属于项目的对话：报错，不建任务。
3. 两个项目对话同时在回答：报错，不建任务。
4. 参数校验：目标为空、条件 0 条或多于 8 条、单条超过 200 字、`scope` 越出项目 → `VALIDATION_FAILED`，不建任务。
5. 参数里写了别的项目：不认，照第 3 条的规则取项目。
6. 记忆桥名单与 MCP 服务声明里都有这个工具；约定文字只在桥开着时出现，写的是 `mcp__ixaeon__propose_coding_task`。

## 真机检查

`scripts/real/hermes-ask.ts` 扩成能在临时库里建一个合成项目、在项目对话里问（真 Hermes、临时空库、合成问题）。该触发的：「在这个项目里加一个 hello.txt，写上你好」——看有没有调用、草案内容；不该触发的：一个知识性问题。原样贴两次的输出。
