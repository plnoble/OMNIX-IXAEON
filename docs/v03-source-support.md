## 通用规范（S2 实现对所有平台同一要求）

- 规范化结构至少保存：平台、本地账户命名空间、稳定对话标识、说话人、
  消息标识、父子/分支关系（原格式提供时）、原始时间、原文、版本、导入方式。
- 无消息 ID/时间/分支时明确缺失标记 + 保守去重（内容指纹），不凭标题合并。
- 跨平台/跨账户相同标题或 ID 不合并（标识含平台+命名空间）。
- 附件/图片/音频未解析时保存元数据+缺失提示；不自动拉取附件 URL；
  不声称已理解内容。
- 再导入只处理新增/变化；编辑保留旧版（版本化，同 ChatGPT 现有语义）；
  重提取不覆盖人工约束与纠正（现有保护集语义沿用）。
- 不读取账户密码或 Cookie（命名空间用用户自命名，不自动探测）。

## 样本需求（需要用户提供）

每平台一份**脱敏**导出（删去敏感内容后仍保留原始结构）：
1. 含至少 2 轮对话、一段编辑/分支（若有）、一条带附件的（若有）；
2. 放入 `docs/samples/`（gitignore 内的本地目录，不入库）或直接告知路径；
3. 提供时注明导出方式与大致版本日期。

拿到样本前，S1（个人层）与解析器无关，可先开发；S2 的对应平台解析项标记受阻。
